UAMS — University Admission Management System

A console-based University Admission Management System (UAMS) developed in C++ as a first-semester programming project.

The application simulates a basic university admission system through a menu-driven console interface and demonstrates fundamental C++ programming and file-handling concepts.

Features

- Student registration
- Student information management
- Student login/authentication
- Admission-related operations
- Student record storage
- Reading and writing student data using files
- Menu-driven console interface
- Basic input validation
- Student record management

Technologies Used

- Language: C++
- Interface: Console / Command Line
- File Storage: Text files
- Compiler: g++ / MinGW

How It Works

The system provides a console-based interface through which users can interact with different admission-related functions.

Student information can be stored in text files, allowing data to persist after the program is closed.

The project was designed to practice programming logic and understand how a basic management system can be implemented using C++.

How to Run

Clone the repository

git clone https://github.com/YOUR-USERNAME/cpp-uams.git

Navigate into the project:

cd cpp-uams

Compile

g++ src/main.cpp -o uams

Run on Windows

uams.exe

Run on Linux / macOS

./uams
